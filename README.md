# smart-display

常駐螢幕用的智慧儀表板，包含時間、天氣、新聞、股市、鬧鐘、夜間模式、背景更換與地震資訊提醒。

## 使用方式

```bash
CWA_API_KEY=你的氣象署授權碼 npm start
```

或先在作業系統／部署平台設定 `CWA_API_KEY` 環境變數，再執行：

```bash
npm start
```

開啟瀏覽器到 `http://localhost:3000`。

## 檔案分工

- `server.js`：提供新聞、股市 API，並送出靜態網頁。
- `index.html`：主要使用者畫面與互動邏輯。
- `main.js`：舊版前端檔案，目前首頁不再載入。

## 安全與運作說明

- 氣象署授權碼只由伺服器環境變數讀取，不會送到瀏覽器。
- 地震功能顯示的是「最新地震報告」，不是官方即時地震預警。
- 新聞、股市及地震報告具有快取與 24 小時離線備援；畫面會標示資料是否過期。
- 低效能模式會減少動畫、雨滴數量及資料更新頻率，可由葉片按鈕切換。
- 伺服器每 30 分鐘清理過期快取，前端每 10 分鐘清理可重建的暫存資料。
